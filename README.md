# Santa Monica Radio

Ретро-радиоплеер бесплатных радиостанций Лос-Анджелеса по жанрам: столбики эквалайзера как на магнитофонах 80-х,
5-полосный эквалайзер, выбор качества потока, режим для машины. Android (APK) + веб-версия для компьютера.

- Концепция и архитектура: [docs/CONCEPT.md](docs/CONCEPT.md)
- Статус и следующий шаг: [docs/PROGRESS.md](docs/PROGRESS.md)
- Инструкция для ИИ-ассистентов: [AGENTS.md](AGENTS.md)
