## Журнал решений

| № | Дата | Решение | Причина |
|---|------|---------|---------|
| D-001 | 2026-11-08 | Два клиента: нативный Android (Kotlin/Compose/Media3) и лёгкий веб (Svelte/TS), общий `stations.json` | Нужны настоящие фон, Android Auto, EQ; кроссплатформенные фреймворки всё равно требуют раздельного аудио-кода |
| D-002 | 2026-11-08 | EQ и спектр на Android — собственные `AudioProcessor` в ExoPlayer | Одинаковые полосы с вебом, не нужно разрешение микрофона, не зависит от прошивки |
| D-003 | 2026-11-08 | Веб обрабатывает звук только через relay | Иначе CORS → тишина в Web Audio (ошибка прототипа), mixed content для HTTP-потоков |
| D-004 | 2026-11-08 | Авторизации iHeartRadio нет; только добавление живых станций по ссылке/поиску | Нет публичного API, логин через неофициальный API нарушает их условия и требует хранить пароль |
| D-005 | 2026-11-08 | Каталог собирается в GitHub Actions и хостится на GitHub Pages | Бесплатно, не нужен свой сервер для данных |
| D-006 | 2026-11-08 | Таймаут старта потока 8 с (было 1.5 с) | 1.5 с недостаточно для редиректа и буферизации, рабочие потоки пропускались |
| D-008 | 2026-11-08 | Избранное в Android хранится в DataStore, а не в Room (на старте) | Не нужен KSP/кодогенерация, меньше риска сломать первую сборку; Room вернём при росте данных |
| D-009 | 2026-11-08 | Cleartext HTTP разрешён для всех доменов | Личное приложение; многие радио-потоки HTTP или редиректят между http/https |
| D-010 | 2026-11-08 | Основной интерфейс на русском (строки в коде, `object T` в `Screens.kt`) | Пользователь читает по-английски с трудом; вопрос Q6 (второй язык) остаётся открытым |

| D-012 | 2026-11-08 | Эквалайзер и анализатор спектра — собственные `AudioProcessor` в цепочке ExoPlayer: EQ → спектр → вывод | Согласовано с D-002; визуализатор показывает звук уже после эквалайзера |
| D-013 | 2026-11-08 | Магнитола пользователя работает по **CarLife**, не Android Auto. Собственный «CarLife-клиент» не делаем (нет публичного SDK/протокола). Вместо этого: корректная `MediaSession` (кнопки руля/Bluetooth), лёгкий **Car mode** для зеркалирования (без анимаций по умолчанию), Android Auto остаётся бонусом | Исследование CarLife: проекция UI приложения телефона, протокол и SDK для сторонних приложений не опубликованы |

Car mode (`CarScreen.kt`) сделан без анимаций, экран не гаснет | Подтверждает D-013: достаточно корректной MediaSession + лёгкий экран |
