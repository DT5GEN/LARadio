2. В Android Studio: Run на телефоне. Проверить: (а) станция играет и столбики двигаются в такт; (б) кнопка **EQ** открывает экран эквалайзера, ползунки и пресеты слышно (например «Меньше баса»); (в) после перезапуска настройки EQ сохранились.

**Версии Android-проекта (проверены сборкой на машине пользователя):** AGP 8.9.1, Gradle 8.11.1, Kotlin 2.1.20, Compose BOM 2025.04.01, Media3 1.6.1, OkHttp 4.12.0, DataStore 1.1.4, compileSdk/targetSdk 35. **Важно:** в Android Studio нужно выбрать Gradle JDK 17/21 (JDK 25 несовместима с Gradle 8.11.1).

**Команды каталога** (из папки `catalog`): `npm run import` (→ `auto.yaml` из Radio Browser, в CI запускается само), `npm run build` (проверка + `dist/stations.json`), `npm run build:offline` (без сети, для встроенной копии в APK), `npm run check`, `npm run discover`, `npm run probe`. Запускать на компьютере пользователя: в облаке ассистента нет доступа к сайтам радио.

## Уроки прототипа (ошибки, которые нельзя повторять)

1. **Web Audio + чужой поток без CORS = тишина.** `createMediaElementSource` не выдаёт ошибку, просто глушит звук; запасной режим не включался. → Граф Web Audio только для потоков через relay.
2. **Таймаут 1.5 с** на старт потока — слишком мало. → 8 с.
3. **HTTP-поток (KJLH) на HTTPS-странице** блокируется браузером. → relay в вебе, `network_security_config` на Android.
4. Адреса StreamTheWorld из прототипа не проверялись с августа 2026. → Автопроверка каталога.
5. В прототипе не было git. → Git с фазы 1.
6. Облачная среда ассистента не видит сайты радио (DNS). → Проверки потоков запускать у пользователя или в GitHub Actions.
