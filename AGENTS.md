# AGENTS.md — инструкция для любого ИИ-ассистента

> Этот файл читают Claude, DeepSeek, ChatGPT, Cursor, Copilot и любые другие ассистенты,
> которые продолжают разработку. Если ты ИИ и впервые открыл этот репозиторий — начни отсюда.

## О проекте в двух предложениях

**Santa Monica Radio** (рабочее название) — лёгкий радиоплеер бесплатных радиостанций Лос-Анджелеса,
сгруппированных по жанрам, с ретро-дизайном 80-х (сегментные столбики эквалайзера, как на магнитофонах),
настоящим 5-полосным эквалайзером, выбором качества потока и режимом для машины.
Две версии: **Android-приложение (APK, Kotlin + Media3)** и **веб-версия (PWA) для компьютера**,
общий каталог станций `stations.json` и маленький сервер-ретранслятор для веба.

## Порядок чтения (обязательно)

1. `docs/PROGRESS.md` — где остановились, что делать дальше, открытые вопросы, журнал решений.
2. `docs/CONCEPT.md` — полная архитектура и спецификации. Это источник истины.
3. Код модуля, с которым предстоит работать (`catalog/`, `android/`, `web/`, `relay/`).

## Правила работы

1. **CONCEPT.md — источник истины.** Если в ходе работы пришлось отступить от концепции —
   добавь запись в «Журнал решений» в `docs/PROGRESS.md` (следующий номер `D-0xx`) и поправь CONCEPT.md.
2. **В конце каждой сессии обнови `docs/PROGRESS.md`:**
   отметь выполненные пункты `[x]`, добавь строку в «Журнал сессий», перепиши раздел «Следующий шаг»
   так, чтобы следующий ассистент мог начать без вопросов.
3. **Язык:** документы и общение с пользователем — по-русски (пользователь читает по-английски с трудом).
   Код, имена файлов, идентификаторы, сообщения коммитов — по-английски.
4. **Маленькие шаги.** Каждый шаг заканчивается рабочим, собираемым состоянием. Не оставляй проект сломанным.
5. **Схема `stations.json`** меняется только с увеличением `schemaVersion` и обновлением обоих клиентов.
6. **iHeartRadio:** не реализовывать вход по логину/паролю через неофициальный API (см. CONCEPT.md §9).
7. **Ретранслятор не делать публичным открытым прокси:** только станции из каталога, доступ по токену (CONCEPT.md §7).
8. **Не удалять** файлы пользователя без явной просьбы. Старый прототип переносится в `legacy/`, а не удаляется.
9. Секреты (ключи подписи APK, токены) — никогда в git. Использовать `.env` / `local.properties` + `.gitignore`.

## Среда пользователя

- ОС: Windows. Папка проекта: `E:\santa-monica-radio-pwa` (на момент старта — без git).
- Тестовый телефон: Google Pixel 7 Pro (актуальный Android). APK ставится напрямую, без Play Market.
- IDE для Android: Android Studio. Опыт Android-разработки у пользователя небольшой — объясняй шаги.
- Пользователь хочет слушать радио в машине (Bluetooth / Android Auto).

## Целевая структура репозитория

```
santa-monica-radio-pwa/          (позже можно переименовать в la-radio)
├── AGENTS.md                    ← этот файл
├── README.md                    ← краткое описание для людей
├── docs/
│   ├── CONCEPT.md               ← архитектура и спецификации
│   └── PROGRESS.md              ← статус, дорожная карта, решения, журнал
├── design/
│   └── tokens.json              ← цвета, шрифты, параметры визуализатора (общие для Android и веба)
├── catalog/                     ← сборка и проверка каталога станций (Node.js + TypeScript)
│   ├── curated.yaml             ← ручной список станций LA
│   ├── src/                     ← скрипты build / check
│   └── dist/stations.json       ← результат (публикуется на GitHub Pages)
├── android/                     ← Android-приложение (Gradle, Kotlin, Compose, Media3)
├── web/                         ← веб-версия (Vite + Svelte + TypeScript, PWA)
├── relay/                       ← ретранслятор потоков для веба (Node.js + TypeScript, Docker)
├── legacy/                      ← старый прототип PWA (index.html, app.js, …) — только для справки
└── .github/workflows/           ← CI: ежедневная сборка каталога, сборка APK
```

## Как запускать (заполнять по мере появления модулей)

| Модуль  | Команда | Статус |
|---------|---------|--------|
| catalog | `cd catalog && npm i && npm run build` | ещё не создан |
| web     | `cd web && npm i && npm run dev` | ещё не создан |
| relay   | `cd relay && npm i && npm run dev` | ещё не создан |
| android | открыть `android/` в Android Studio → Run | ещё не создан |

## Шаблон запроса для продолжения в другом ассистенте

Скопируй и вставь в новый чат вместе с содержимым `AGENTS.md`, `docs/PROGRESS.md`, `docs/CONCEPT.md`:

```
Ты продолжаешь разработку проекта Santa Monica Radio. Прочитай AGENTS.md, затем docs/PROGRESS.md
и docs/CONCEPT.md. Выполни задачу из раздела «Следующий шаг» в PROGRESS.md. Общайся со мной по-русски.
Работай маленькими шагами, после каждого шага скажи, как проверить результат.
В конце сессии выдай обновлённый docs/PROGRESS.md целиком.
```
